# Decision Tree Learning
A Machine Learning implementation of Decision Tree classification using Python and Scikit-learn with a Traffic Signal dataset.

## Technologies Used
* Python
* Scikit-learn
* Pandas
* NumPy
* Matplotlib
* Google Colab

## Dataset
Traffic Signal Dataset.

## Workflow
1. Load the Traffic Signal Dataset
2. Prepare the data
3. Select features and target
4. Build the Decision Tree model
5. Train the model
6. Visualize the Decision Tree
7. Classify a new sample
8. Evaluate the model

## Purpose
This repository demonstrates Decision Tree classification using a Traffic Signal dataset and applies the trained model to classify new samples.
